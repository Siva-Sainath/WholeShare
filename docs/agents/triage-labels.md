# Triage Labels

The canonical role strings for issue triage in this repo:

- `needs-triage`: A new issue that has not yet been reviewed or scoped.
- `needs-info`: Requires additional feedback from the user or stakeholders before work can proceed.
- `ready-for-agent`: Fully specified and ready for autonomous agent execution.
- `ready-for-human`: Requires manual intervention or decisions that only a human operator can make.
- `wontfix`: Scoped out or rejected.
